# Manga Radar — site V6

Prototype statique prêt pour GitHub Pages.

## Fichiers
- `index.html` : page du site
- `style.css` : design responsive iPhone/desktop
- `app.js` : dashboard, recherche et filtres
- `data.js` : données extraites de `Manga_Radar_V6.xlsx`
- `Manga_Radar_V6.xlsx` : source des données

## GitHub Pages
Le site peut être publié à la racine du dépôt avec `index.html`.
